# API CLI

## Overview

API CLI is a command-line client for interacting with the PERUN API.

The utility provides functionality for managing sandbox analysis tasks and retrieving generated artifacts from completed analyses.

## Features

API CLI supports the following operations:

- Uploading analysis samples
- Listing sandbox tasks
- Checking task status
- Listing files generated for a task
- Downloading task artifacts
- Resuming interrupted artifact downloads
- Retrieving DataMiner analysis results

Supported artifacts may include:

- Network capture files (`.pcap`)
- Memory dumps
- Process monitoring outputs
- Additional task-generated files

The `download` command supports download resumption.

If a download is interrupted, rerunning the same command will continue downloading the remaining data instead of restarting the transfer from the beginning, provided that the partial output file is still present.

## Configuration

API CLI supports configuration through environment variables and profile-based configuration files.

### Environment Configuration

Create a `.env` file in the project directory.

Example:

```env
api_url="https://perun-api/v1"
token="my-secret"
profile="default"
config_file=".config"
```

#### Available Variables

| Variable      | Description                               | Required |
| ------------- | ----------------------------------------- | -------- |
| `api_url`     | PERUN API endpoint including version path | Yes*     |
| `token`       | Authentication token                      | Yes*     |
| `profile`     | Configuration profile to use              | No       |
| `config_file` | Path to configuration file                | No       |

*Required unless provided through command-line arguments.

Default values:

| Variable      | Default   |
| ------------- | --------- |
| `profile`     | `default` |
| `config_file` | `.config` |

### Profile Configuration

Profiles are defined in a configuration file.

Example `.config`:

```ini
[default]
plugins = apimon,filetracer,memdump,procmon,socketmon,tlsmon
timeout = 30
template =
```

#### Configuration Options

| Option            | Description                                                                   |
| ----------------- | ----------------------------------------------------------------------------- |
| `plugins`         | Comma-separated list of PERUN Sandbox plugins used by default during uploads  |
| `timeout`         | API request timeout in seconds                                                |
| `template`        | Sandbox template name, empty template defaults to server's default            |

## Command-Line Interface

API CLI uses `argparse` and provides built-in help for all commands.

General syntax:

```text
main.py [-h]
        [--api-url API_URL]
        [--token TOKEN]
        [--timeout TIMEOUT]
        [--profile PROFILE]
        {upload,list,status,files,download,analysis}
```

### Available Commands

| Command    | Description                             |
| ---------- | --------------------------------------- |
| `upload`   | Upload a file and create a sandbox task |
| `list`     | List all task identifiers               |
| `status`   | Retrieve task status                    |
| `files`    | List files available for a task         |
| `download` | Download a file generated by a task     |
| `analysis` | Retrieve DataMiner analysis results     |

### Global Options

| Option      | Description           |
| ----------- | --------------------- |
| `--api-url` | API endpoint URL      |
| `--token`   | Authentication token  |
| `--timeout` | Request timeout       |
| `--profile` | Configuration profile |

Command-line arguments take precedence over values provided through `.env` files and profile configuration.

## Examples

Upload a sample using selected plugins:

```bash
main.py upload malware.exe 60 --plugins procmon tlsmon
```

List available tasks:

```bash
main.py list
```

Check task status:

```bash
main.py status <task-uid>
```

List files generated by a task:

```bash
main.py files <task-uid>
```

Download a task artifact:

```bash
main.py download <task-uid> dump.pcap --output <task-uid>.pcap
```
